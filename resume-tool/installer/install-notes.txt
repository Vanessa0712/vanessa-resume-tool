Resume Tool 安装前须知

一、数据保存在哪里
程序本身装进安装目录，但简历库、上传的原文件、模板、备份和 API Key 全部保存在：
    %LOCALAPPDATA%\ResumeTool

因此升级或重装程序都不会动到你的数据。

二、首次启动
安装完成后勾选「启动 Resume Tool」，程序会在后台启动并自动打开浏览器。
如果没有弹出，手动访问 http://127.0.0.1:5000。

三、怎么关闭程序
关闭浏览器标签页只是关掉页面，后台程序仍在运行。
要彻底退出：打开「设置」页，用最下方的「退出程序」按钮。

四、迁移旧数据
如果之前在别的电脑或源码目录里用过，把下面三项复制到上面的数据目录即可：
    resume_tool.db
    uploads\
    config\

五、看到「Windows 已保护你的电脑」
安装包暂未购买代码签名证书，SmartScreen 可能提示"未知发布者"。
点「更多信息」→「仍要运行」即可继续。

六、杀毒软件误报
程序由 PyInstaller 打包，个别杀软会对这类自解压结构报"可疑"。
如被拦截，请把安装目录加入信任列表后再运行。
